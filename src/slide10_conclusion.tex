  \slideheader{Conclusion}

  \vspace{16mm}
  {\small The preprocessing core provides a compact, reusable path from declarative configuration to a reproducible in-memory \texttt{DatasetBundle}.}\par

  \vspace{4mm}
  \begin{itemize}
    \item YAML defines the workflow without embedding pipeline logic in notebooks or scripts
    \item Typed config and pipeline classes keep execution consistent and inspectable
    \item Public registries let private repositories add loaders, transforms, and splitters cleanly
    \item The result is a standard \texttt{DatasetBundle} ready for downstream modeling
  \end{itemize}
